## Naya note kaise daalein

GitHub pe repo kholo → `docs/` ke andar folder chuno → **Add file → Upload files** → `.md` file drop karo → Commit. Ya seedha "Create new file" se browser mein hi likh lo.

~40 second baad note site pe live aur searchable hota hai. Naya folder chahiye to filename mein `folder/note.md` likh do — GitHub khud bana dega, nav khud update ho jayegi.
