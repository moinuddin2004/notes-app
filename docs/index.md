## Note ka format

```yaml title="docs/python/requests.md"
---
title: Python — requests library
tags:
  - python
  - library
date: 2026-08-30
---
```

Uske baad heading structure kuch aisi rakho — har note ek jaisa lagega aur dhoondhna aasan hoga:

```markdown
# requests

## Ek line mein     ← 1–2 line ka summary
## Install
## Core concepts    ← table best kaam karta hai
## Examples         ← code tabs
## Gotchas          ← warning boxes
## Cheatsheet       ← quick-reference table
```
